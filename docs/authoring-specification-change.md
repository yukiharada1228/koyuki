# 既存業務の仕様変更を試す

対象はac39f8aで追加した予約キャンセル。既存fixtureを変更前として実際に配布tarballへ接続し、同じ別プロジェクト内で変更後へ置き換えて型検査と実行を行う。フレームワークの内部ソースはimportしない。保守者AIによる評価であり、React経験者本人の習得時間を測ったものではない。

再現コマンド: `npm run test:authoring:change`。未使用の一時ディレクトリに試用パックを準備し、開発版tarballをインストールする。ReactとNode型の不在を検査し、変更前・変更後の型検査と実行を順次行う。作成した一時ディレクトリだけを終了時に削除する。npm公開はしない。

## 要求と状態

開始24時間前までは予約者本人がキャンセルできる。24時間ちょうどを含み、1ミリ秒でも過ぎれば拒否する。時間はUTCのepochミリ秒で比較する。操作者と時計はホストがProviderへ渡し、操作入力にはidのみを許可する。暦日・営業日計算は今回の仕様に含めない。

| 入力状態・条件 | 結果 | 保存 |
|---|---|---|
| booked・本人・24時間以上前 | cancelled | 1回 |
| booked・本人・24時間未満 | CancellationClosed | なし |
| booked・他人 | Forbidden | なし |
| cancelled・本人 | AlreadyCancelled | なし |
| 取得失敗 | Missing | なし |
| 時刻が安全な整数でない | InvalidTime | なし |

最初の認可失敗で止め、無関係な期限判定まで進めない。成功時には元の予約を変更せず、新しいcancelledを作る。

## 変更が広がった範囲

| 箇所 | 初回の期限導入 | 24時間→48時間 |
|---|---|---|
| 状態型 | booked/cancelledへstartsAt追加 | 変更なし |
| 業務関数 | nowを受け取り、期限検証を合成 | 期限比較の1式 |
| Repository契約 | 返すBookingにstartsAtが必要 | 変更なし |
| Hook/load | Clock取得と実行時nowの付与 | 変更なし |
| Provider | ホストのClockを追加 | 変更なし |
| JSXのOperation登録・操作ID・execute | 変更なし | 変更なし |
| フレームワーク実行エンジン | 変更なし | 変更なし |
| テスト | 時刻データ・期限・失敗検証を追加 | 境界時刻と期待値を更新 |

元のfixtureには開始時刻も時計もなかったため、最初の変更は業務関数だけには閉じなかった。必要な依存の追加まで自動化できるとはしない。Providerでは時計関数だけを確保し、loadが呼ばれるたびに読み取る。同じアプリを再利用しても部品評価時の古い時刻を使わない。取得結果へactor/nowを添えるResult分岐は手書きで残った。未検証入力からの自動注入は加えなかった。

48時間への変更では、業務の比較式とテストデータだけを変更する。Hook・Provider・保存・登録・実行コードは同じ文字列のまま。以前許可した24時間前が新しい仕様では拒否されることも検査する。これは特定の小さな変更の結果であり、任意の仕様変更が局所化する保証ではない。

## 検証内容と限界

変更前fixtureと変更後fixtureをTypeScript 7で型検査し、配布パッケージを使って実行する。境界の前後1ms、当日・開始後、既存の認可・状態エラー、取得失敗、不正時刻を検査する。失敗でsaveが増えず、期限失敗ではcancelのtraceも出ない。別操作者の並行実行と、純粋関数へのfreezeした入力の非破壊も検査する。入力へnowを混ぜる呼び出しを拒否し、新しいエラーUnionが戻り型へ伝播することを型で確認する。

負の対照として、24時間ちょうどを誤って拒否する`>`への変更は型検査を通るが業務テストで落ちる。clock関数自体を時刻として渡す誤配線は型検査で落ちる。初回試行ではテスト用assertion関数の型絞り込みがループ変数へ影響し、TS7022となったため、絞り込みを必要としないvoidの検査関数へ変更した。業務APIの型引数は増やしていない。

メモリRepositoryによる試用であり、期限を確認してから保存する間の時間経過、同時更新の競合、永続再送は今回の対象外。本番で「保存時点にも期限内」を要求するなら保存境界でも検査する必要がある。今回の24時間制限はload後に読んだ時刻で判定する仕様。三業務のSQLite検証や講演全内容の反映を、この試用の成功だけで証明したとはしない。
