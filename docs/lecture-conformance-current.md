# 現在の実装と講演全体の対応

今回の要求は3講演全体への準拠であり、中心思想やテストだけに範囲を縮めて完成とはしない。実装の照合基点はa436f39。前回の9つのpartialや未確認の原音を、JSX API・追加業務・期限変更の成功だけでsupportedへ変更しない。

## 現在の再現手順

```sh
node scripts/check-lecture-conformance.mjs --report /tmp/koyuki-lecture-conformance.json
```

保存済み3講演の84話題を重複なく列挙し、参照ファイルの存在を確認する。最新のHook登録・再利用・仕様変更・capture・登録の検証を該当話題へ追加したうえで、型検査、講演記録検査、全runtimeテスト、TypeScript 6/7配布物検証、既存業務の仕様変更検証を実行する。成功したコマンドと出力はreportに残る。各話題のassessmentとremainingも出力する。

参照ファイルが存在することと、主張が証明されたことは異なる。スクリプトは語義や実装の意味を自動判定しない。原音を聴いたことにも、人間による評価にも置き換えない。全検査が成功してもcompleteLectureConformanceProvenはfalseと明記する。

不要な機能を足してpartialの数だけを減らすことはしない。特定のメール事業者、強制的な全値ログ、React内部実装、言語組込みdo構文の再現を根拠なく必須に追加しない。一方、上の制限を消したとも主張しない。

現在利用できる確認手段には、ローカル原音を直接聴取して否定・用語を確定できる経路がない。既存の字幕・別ASR・画面抽出だけで不確定発話を確定することはできず、「講演全体への完全準拠」という受入条件は未達のままである。原音が確定した時点で該当10区間と設計への影響を再判定する必要がある。
